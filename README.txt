KEN JEE HAIR SALON - Website
=============================
Open index.html in any browser (no server needed).

Files: index.html, css/style.css, js/app.js, images/

Accounts
- Client: Log in > Sign up > choose Client.
- Admin: Sign up > choose Admin > enter the access code KENJEE-ADMIN
  (change ADMIN_CODE at the top of the account code in js/app.js).
- Admin panel (nav "Admin"): accept/decline reservations, mark days fully booked, post promos.

Notes
- Data is stored in the browser's localStorage, so reservations are visible only on the same
  browser/computer. To share data between devices, connect a backend (e.g. PHP + MySQL).
